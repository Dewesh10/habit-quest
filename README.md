## 🔥 Features Overview

### 📊 1. Hunter Status Window & Free Stat Allocations (AP)
- **Job Class Progression**: *None → Necromancer → Shadow Monarch*
- **Stats**: Spend free AP into **STR, VIT, AGI, INT, PER**.
- **Dynamic Combat Power (CP)**: Calculated based on level, stats, equipped weapons, and active Shadow Army power.
- **HP / MP / EXP Gauges**: Translucent cyan & Monarch purple glassmorphism HUD.

### 🏋️ 2. Non-Skippable Daily Quests & Emergency Penalty Zone
- **"Preparations to Become Strong"**: Push-ups (100 reps), Sit-ups (100 reps), Squats (100 reps), Running (10 km).
- **Emergency Penalty Zone**: If daily quests are neglected, a red siren warning overlay triggers with a temporary -20% stat debuff and a forced survival quest.

### 🎓 3. College Student System Mode
- **Discipline Specializations**: Computer Science, Pre-Med, Business, Law, Natural Sciences, Arts, and General Academic.
- **Academic Daily Directives**: Lecture attendance, deep study blocks, and assignment milestones.
- **Semester Exam Raid Gates**: Midterm Raids & Finals S-Rank Gates with study hour targets and GPA boosting.

### 🏰 4. Dungeon Gates & Shadow Army Extraction ("ARISE")
- **Gate Raids**: Clear E-Rank, C-Rank, A-Rank, and S-Rank Red Gates by completing habit objectives.
- **Shadow Extraction (ARISE)**: Defeat Dungeon Bosses (*Kasaka*, *Commander Igris*, *Demon King Baran*, *Ant King Beru*) to extract **Igris, Iron, Tusk, Beru, and Bellion** for passive category XP multipliers.

### 🎒 5. System Store & Inventory
- **Gold Currency**: Earned from completing quests, daily directives, and gate raids.
- **System Store**: Buy Status Recovery Potions, Gate Keys, and Artifact Weapons (*Knight Killer's Dagger*, *Demon King's Longsword*).
- **Equipment Slot**: Equip weapons for instant stat boosts and CP gains.

### 🔊 6. Web Audio API Sound System
- Procedurally synthesized sound effects for System Alert pings, Quest Chimes, Level Up Fanfares, Penalty Sirens, and **ARISE** Shadow Extraction energy swells.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Routing**: React Router DOM v7
- **Styling**: Vanilla CSS + Tailwind CSS v4 + Glassmorphism HUD
- **Animations**: Framer Motion + HTML5 Canvas Particle Engine
- **Icons**: Lucide React
- **Audio**: Web Audio API Synthesizers

## 💻 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/Dewesh10/habit-quest.git
cd habit-quest

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build
```
